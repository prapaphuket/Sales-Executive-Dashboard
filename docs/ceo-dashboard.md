### Insight บน Executive (ท้ายหน้า ต่อจากข้อเสนอแนะ · ลิงก์ไปหน้าที่เกี่ยวข้อง)
1. ยอดออกบิล YTD และ YoY → `#growth`
2. ต้นทุนระบบผลิตเดือนล่าสุดตาม GL เทียบเดือนก่อน และหมวดที่เปลี่ยนมากที่สุด → `#finance`
3. งานโครงการที่ถึงกำหนดถัดไป (จาก `next` ของโครงการใน ClickUp) และจำนวนงานเกินกำหนด → `#projects`
4. งานซ่อมระบบผลิตค้าง/รอช่าง และค้างนานสุด → `#maint`
5. ใบเสร็จที่ผูกใบแจ้งหนี้ผิดใน TRCLOUD → `#meter`

### ผลตรวจก่อนส่งมอบ
- `scripts/validate.py` ผ่านทุกข้อ · โค้ดคำนวณยอด (`salesAgg`) ไม่เปลี่ยน
- ลบ `finance.json` + `trc_recon.json` ชั่วคราว: Executive โครงการ ซ่อมบำรุง การเงิน จดมาตร เปิดได้ ไม่มี error
- ยอด WMS กับ TRCLOUD แสดงแยก ไม่รวมกัน · ไม่ใช้ PO/AP/EXP · BL/IV ใช้เพื่อติดตามเอกสารเท่านั้น
- ทุกหน้าใน 3 ธีม ไม่มี error · จอ 390 px ไม่ล้นแนวนอน · CSV ดาวน์โหลดได้ · build แบบเข้ารหัสด้วยกุญแจทดสอบผ่าน

ค่าเริ่มต้นแสดงเฉพาะ List ของ Operation: แหล่งน้ำ · อ่างเก็บน้ำ · การผลิต/โรงงาน · ซ่อมบำรุง/ติดตั้งมิเตอร์ · Outsource จดมิเตอร์/ฝ่ายผลิต (ตั้งใน `OPS_LISTS` ของ `public/app.js`) · ปุ่ม “ทั้งหมด” ที่หัวหน้า แสดงทุก List · Insight โครงการบนหน้า Executive นับเฉพาะ Operation · ไม่แสดงงานของฝ่าย IT (`EXCLUDE_OWNERS`)

## ข้อจำกัดที่ต้องรู้
- **GL TRCLOUD:** บัญชีต้นทุนผลิตเริ่มมีรายการ ม.ค. 2569 จึงไม่เทียบปีก่อน · ม.ค.–ก.ค. ของ 5101002/5101003/5101004 มาจาก JV ปรับปรุงที่ลง 3 ก.ย. 69 · ไม่รวมภาระผูกพันตาม PO
- **ClickUp:** โครงการ = งานระดับบนสุดที่มีแผนงาน/milestone เป็นงานย่อยพร้อมกำหนดส่ง (ตั้งชื่อแนวท่อ ×2, trade zone, Outsource 4 ระยะ) · **ไม่แสดงงานที่ผู้รับผิดชอบเป็น wichan boonchaiyo (ฝ่าย IT: RMS, WMS, Data logger, Pipe Survey, แบบฟอร์มขอใช้น้ำ) — ตั้งใน `EXCLUDE_OWNERS` ของ `scripts/clickup_projects.py`** — ที่เหลือแสดงแยก "รอยืนยันว่าเป็นโครงการ" · นับเฉพาะงานย่อยระดับแรก · ตัดงานระดับบนที่ยกเลิก 29 รายการ · ไม่คำนวณ % ความคืบหน้า · Resource Utilization = ข้อมูลไม่พอ
- **ซ่อมบำรุง:** จัดกลุ่มจากประเภทใบงานก่อน (IT Helpdesk = IT) แล้วจึงประเภท/ชื่อเครื่องจักร · ปิดงานที่รหัสผลซ่อม "ยกเลิกการซ่อม" = ปิดโดยไม่ได้ซ่อม (4 ใบ) · ไม่คำนวณชั่วโมงหยุดผลิต (ไม่มีเวลาเริ่ม–สิ้นสุดการหยุด) · ไม่ใช้คะแนน Auto Evaluate · ค่าซ่อมจาก GL ไม่เฉลี่ยลงใบงาน
- **BL/IV:** ยังไม่มี log การส่ง API จึงไม่คำนวณอัตราส่งสำเร็จ · ใบเสร็จ 37 ใบผูกใบแจ้งหนี้คนละใบใน TRCLOUD · ใบลดหนี้ไม่ถูกส่งเข้า TRCLOUD

## อัปเดตรอบถัดไป
1. ClickUp / GL: ให้ Claude ดึงผ่าน MCP (อ่านอย่างเดียว) แล้วรัน `python scripts/clickup_projects.py` และ `python scripts/finance_from_gl.py`
2. ไฟล์ซ่อมรอบใหม่: วางใน `data/maintenance/` แล้วรัน `python scripts/maintenance_import.py data/maintenance/<ไฟล์>.xlsx`
3. Build ตามเดิม: `node scripts/build-static.js --key C:\mcp\keys\hea-dash-key.txt --out site`
