## 4. การจัดกลุ่มที่ต้องรู้

- ประเภทลูกค้า สาขา ใช้ค่าปัจจุบันในทะเบียนผู้ใช้น้ำ (ไม่ใช่ค่า ณ วันที่ออกบิล) ยกเว้นยอดขายที่ใช้ `branch_id` ของเอกสาร
- รายการที่ไม่มีประเภท/สาขา/หมู่ แสดงเป็น “ไม่ระบุ/รอตรวจสอบ” ไม่ตัดทิ้ง
- ในกราฟ สาขาที่ปิดแล้ว (นาเตย หล่อยูง) และ “ไม่ระบุ” รวมเป็น “อื่น ๆ (สาขาปิด/ไม่ระบุ)” ส่วนตารางและตัวกรองยังแยกตามจริง
- ยอดรับชำระตามใบเสร็จ **ยังไม่ได้กระทบยอดกับบัญชีธนาคาร** จึงไม่ใช้คำว่า “เงินสดรับจริง”

## หน้า การจดมาตร (`sql/16_meter_reading.sql`, ชุดข้อมูล `meter_reading`)

ตารางต้นทาง: `water_meter_records` (รายการจดหน่วยน้ำ, `resp_date` = วันแรกของรอบ) + `record_invoices.water_meter_record_id` + `vw_dash_customer_waters` (ไม่อ่านตาราง `customers` โดยตรง) · อ่านอย่างเดียว

| ตัวชี้วัด | นิยาม |
|---|---|
| รอบ | เดือนล่าสุดที่มีรายการจด (`max(date_trunc('month', resp_date))`) |
| ทะเบียน | ผู้ใช้น้ำสถานะ `active` (สถานะปัจจุบัน — ระบบไม่เก็บประวัติสถานะรายวัน) |
| อ่านแล้ว | ทะเบียนข้างต้นที่มีรายการจดในรอบ (status ≠ cancelled) นับ 1 ครั้งต่อทะเบียน |
| ค้างจด | ทะเบียน − อ่านแล้ว |
| ดีเลย์ (วัน) | วันอ้างอิง − วันสิ้นเดือนของรอบ (บวก = เลยกำหนด) · เริ่มจดวันที่ 20 ต้องครบวันสิ้นเดือน · เหลือ ≤ 3 วัน = เหลือง (เกณฑ์รอยืนยัน) |
| แผนรายวัน | เส้นตรงจาก 0% (เริ่มวันที่ 20) ถึง 100% (วันสิ้นเดือน) |
| หน่วยผิดปกติ | `meter_wrong_show` = 2 (เกิน 200% ของเฉลี่ย 3 เดือน) หรือ 3 (ต่ำกว่า 20%) ตามที่ WMS คำนวณ · เฉลี่ย 3 เดือน = หน่วย × 100 ÷ `meter_wrong_show_percent` |
| ใบแจ้งหนี้ในรอบ | ใบแจ้งหนี้ (ไม่ยกเลิก) ที่ออกในเดือนของรอบ = จากการจดในรอบ + ไม่มีการจดในรอบ (สร้างเอง/นำเข้า) |

## มิเตอร์ไม่หมุน (17_meter_stuck.sql)

## นิยามจดแล้ว (หน้าจดมาตรและออกบิล, ยืนยัน 11/11/69)

- จดแล้ว = จดผ่านเครื่องโมบาย (บันทึกเลขแล้วออกใบแจ้งหนี้ทันที) + บันทึกที่สำนักงาน (ทอท. ไม่ผ่านเครื่อง) → ต้องเท่ากับใบแจ้งหนี้ค่าน้ำในรอบ
- ทะเบียนที่ต้องจด = สถานะใช้งาน − ติดตั้งหลังวันเริ่มจด + ทะเบียนที่จดในรอบแล้วถูกงดจ่ายน้ำภายหลัง
- ช่องทางจด: รายการจดที่มีพิกัด GPS = จดหน้างานด้วยเครื่องโมบาย · ไม่มีพิกัด = คีย์จากเคาน์เตอร์ที่สำนักงาน (`water_meter_records.lat`) · ทอท. = ไม่มีรายการจด ออกบิลตามแบบฟอร์มสัญญา
- ตัวอย่าง ต.ค. 69: หน้างาน 2,967 + สำนักงาน 6 (คีย์ในระบบ 5 + ทอท. 1) = 2,973 = ใบแจ้งหนี้ 2,973 · ทะเบียนที่ต้องจด 2,977 − 4 + 2 = 2,975 · ค้างจด 2
