| `--text-2`, `--text-3` | #4A5160, #5F6675 | ข้อความรอง/คำอธิบาย (7.96:1, 5.76:1) |

Aqua, Sage และ Olive Sage ต้นฉบับไม่ใช้เป็นข้อความบนพื้นขาว · ผล contrast ทั้งหมดอยู่ใน `validation_results.md`
ข้อจำกัด: สีแบรนด์โทนอ่อนมี chroma ต่ำ ผู้มีภาวะบกพร่องการมองเห็นสีอาจแยกสีกราฟชุดรองได้ยาก จึงมี legend ทุกกราฟ ขอบขาวคั่นแท่ง และปุ่ม “ตาราง” แสดงตัวเลขทุกกราฟ

## Typography

| ระดับ | ขนาด | น้ำหนัก |
|---|---|---|
| ชื่อหน้า | 30px | SemiBold 600 |
| หัวข้อส่วน | 20px | SemiBold 600 |
| ตัวเลข KPI | 34px | SemiBold 600 |
| ข้อความ/ตาราง | 14–15px | Regular 400 |
| คำอธิบาย | 12–13px | Regular 400 |

- ฟอนต์: **Prompt** (ไทยและอังกฤษ) น้ำหนัก 400/500/600/700 จาก `@fontsource/prompt` 5.2.6 (SIL Open Font License) วางไว้ใน `public/vendor/fonts/`
- **ไม่ได้ใช้ Gill Sans** — ไม่มีไฟล์และสิทธิ์ใช้งานบนเว็บ จึงใช้ Prompt สำหรับภาษาอังกฤษชั่วคราวตามข้อกำหนด หากได้ไฟล์ webfont ที่มีสิทธิ์แล้ว เพิ่ม `@font-face` และใส่ `'Gill Sans'` ก่อน `'Prompt'` ใน `--font` สำหรับข้อความภาษาอังกฤษ
- ตัวเลขใช้ `font-variant-numeric: tabular-nums` · line-height 1.6 เพื่อไม่ให้สระ/วรรณยุกต์ไทยถูกตัด

## โลโก้

| ไฟล์ | ที่มา | การใช้ |
|---|---|---|
| `public/assets/hea-logo-white@2x.png` (560×321) | ภาพโลโก้เวอร์ชันสีขาว (White Version / Dark BG) ที่ฝังใน HEA_Brand_Guidelines.pdf ตัดจากภาพต้นฉบับโดยไม่แก้ไขสี/สัดส่วน | แถบเมนู Navy แสดงกว้าง 132px (แท็บเล็ต 72px = ขนาดขั้นต่ำ digital) |
| `public/assets/hea-logo-white.png` (1467×841) | ภาพเดียวกันความละเอียดเต็ม | สำรอง |

- Clear space: x = ความสูง symbol mark (≈ ความสูงโลโก้ 76px ที่ขนาดแสดงผล) — เว้นบน/ล่าง 76px ซ้าย/ขวา 84px (แท็บเล็ต 42/48px ที่ x ≈ 41px)
- **ไม่ได้วางโลโก้สีเต็มบนพื้นขาวที่ส่วนหัว** ตามข้อ 9.5 เพราะภาพโลโก้สีเต็มใน PDF ส่วนตัวอักษรเป็นกล่องสีทึบ (placeholder) ใช้ไม่ได้ และห้ามพิมพ์ข้อความจำลองโลโก้ — **ต้องขอไฟล์โลโก้สีเต็ม (SVG/PNG) ทางการ** แล้ววางที่ส่วนหัวพื้นขาว
- ไม่ยืด ไม่เปลี่ยนสี ไม่ใส่เงา (`height: auto`)
